<Update label="2026-05-10" description="Weekly release" tags={["Features"]}>

## New features

- **AI itinerary timeline in chat.** When the AI assistant reads an excursion itinerary or runs a travel-time check, it now renders an itinerary timeline directly in the chat panel — with each event, travel windows between events, route totals, and clear status badges for tight or unknown transitions. See [Timeline tab](/timeline-tab).

</Update>

<Update label="2026-05-09" description="Weekly release" tags={["Features", "Updates"]}>

## New features

- **Weather data on excursions.** Excursions now pull live weather information for their location, with a refresh action so you can pull the latest forecast on demand. See [Excursions](/excursions).
- **AI-suggested visual identity.** Get AI-generated icon and color suggestions for excursions and excursion types directly from the visual identity editor, so it's faster to give each one a recognisable look. See [Excursions](/excursions).
- **Workspace status badges on excursions.** Excursion lists and cards now display your workspace-defined status as a colored badge, replacing the previous generic status label so you can scan custom statuses at a glance. See [Excursions](/excursions).

## Updates

- **Customizable sidebar icon colors.** Sidebar navigation icons now support custom colors, with sensible defaults across the workspace for a more consistent visual hierarchy.
- **More resilient excursion actions.** Excursion edits—covering details, schedule, location, members, status, and visual identity—now surface clearer errors when something goes wrong, so failures are easier to understand and recover from.
- **Refined fortnight calendar icon.** The fortnight view on the excursion timeline uses a refreshed calendar icon for better visual consistency. See [Timeline tab](/timeline-tab).
- **Polished rainbow button in dark mode.** The accent rainbow button now renders cleanly across light and dark themes.

</Update>

<Update label="2026-05-08" description="Weekly release" tags={["Features", "Updates", "Fixes"]}>

## New features

- **Departure and return times on excursions.** Set explicit departure and return times when creating or editing an excursion, with validation to ensure the return time is after the departure time. See [Excursions](/excursions).
- **Contextual help on excursion editors.** Open information dialogs and tooltips from the excursion details page to learn more about properties, location, and schedule fields as you fill them in. See [Overview tab](/overview-tab).
- **Staff picker for task assignment.** Assign tasks to staff using a searchable combobox that shows each staff member's name and email. See [Tasks](/tasks).

## Updates

- **Refined excursion schedule editor.** The schedule editor now uses a unified date and time picker, displays departure and return times in a clearer card layout when not editing, and tightens spacing for a more compact view.
- **Color-coded risk grid rows.** Rows in the Risk Management Bank and excursion risk grids now use color differentiation to make risk types easier to scan at a glance. See [Risk Management Bank](/risk-bank-page).
- **Toolbar actions in data grids.** Data grid toolbars support trailing actions, giving more room for relevant controls alongside search and filters.

## Fixes

- Clarified the read-only departure and return markers on the excursion timeline by directing you to update times from the Overview tab. See [Timeline tab](/timeline-tab).

</Update>

<Update label="2026-05-06" description="Weekly release" tags={["Features", "Updates"]}>

## New features

- **Fortnight calendar view.** A new two-week view is available on the excursion Timeline, giving you a wider window to plan multi-day events at a glance. See [Timeline tab](/timeline-tab).
- **Drag to reschedule itinerary events.** Move events directly on the calendar by dragging them, and adjust start or end times by dragging their edges—no need to open the event form for quick timing changes. See [Timeline tab](/timeline-tab).

## Updates

- **Live time change preview.** While dragging an event or its edges, the calendar now shows a preview of the new time range so you can see exactly where it will land before letting go. Available across day, week, and month views.

</Update>

<Update label="2026-05-05" description="Weekly release" tags={["Features", "Updates", "Fixes"]}>

## New features

- **AI chat in workspaces.** A new AI chat is available across your workspace, with a dedicated shell you can open from anywhere to ask questions and get help. Conversations are saved per workspace so you can pick up where you left off.
- **Archive, rename, and revisit chats.** Manage your AI chats with archive and rename options, browse a list of past chats, and jump back into any active conversation.
- **AI tools for excursions.** The AI assistant can now read excursion context and act on excursions through a curated set of tools, with built-in approval handling so changes only apply when you confirm them. See [Excursions](/excursions).
- **Customizable risk tree view.** Toggle which fields appear in the excursion risk tree—description, lead role, severity, and likelihood—so you can focus on what matters for the task at hand. See [Risk management tab](/risk-management-tab).

## Updates

- **Clearer AI tool statuses.** AI tool runs now show dynamic status badges and refined icons, so you can see at a glance whether a tool is pending, running, or complete.
- **Better failure handling for AI tools.** When an AI tool fails, the assistant explains what went wrong and prompts you to retry by sending another message.
- **Smoother excursion details loading.** The excursion details page supports a default tab and uses a refreshed skeleton across Emails, Forms, Website, Reviews, and Settings tabs for more consistent loading.

## Fixes

- Improved styling for matched items in tree views, making search highlights easier to read in both light and dark themes.

</Update>

<Update label="2026-05-04" description="Weekly release" tags={["Features", "Updates", "Fixes"]}>

## New features

- **Activity types in workspace settings.** Activity types now have their own dedicated section in workspace settings, where you can create, edit, and deactivate activity types with custom names, icons, and colors. See [Settings](/settings-tab).
- **Supervision ratios on excursion and activity types.** Excursion types and activity types now support supervision ratio fields—including students per staff and acceptable and unacceptable thresholds with custom colors—so safety standards are clearer when planning. See [Excursions](/excursions).
- **Excursion and activity type on excursion details.** The excursion details page now shows the assigned excursion type and activity type, with an inline editor for updating the assignment without leaving the page.

## Fixes

- Fixed an issue where activity types could fail to load in excursion settings when no value was set.
- Improved how activity type selection resets when changing excursion types in the assignment editor.

</Update>

<Update label="2026-05-03" description="Weekly release" tags={["Features", "Updates", "Fixes"]}>

## New features

- **Workspace billing.** A new Billing tab is available in workspace settings for workspaces with billing enabled, so admins can manage their subscription in one place. See [Settings](/settings-tab).
- **Pro plan with per-seat pricing.** Subscribe to the Pro plan with licensed per-seat pricing at checkout. Metered usage-based prices are rejected up front to keep billing predictable.
- **Grouped parent rows in participants.** The participants list now visually groups students with multiple parents into a single row span, making family relationships easier to scan. See [Participants](/participants-tab).

## Updates

- **Data grid group headers.** Data grid columns can now be organized under group headers, with tooltips for extra context and accessibility improvements when scanning multi-column tables.
- **Smarter long text cells.** Long text cells in data grids adapt to row height and truncate cleanly, so content stays readable across both single rows and grouped rows.
- **Compact split lists.** Split list cells (such as on participant rows) support a more compact layout for a tighter, more consistent presentation in dense tables.
- **Custom empty states.** Split list cells now show a clearer empty-state indicator when there's nothing to display.

## Fixes

- Fixed inconsistent height behavior in split list cells so rows align reliably across the grid.

</Update>

<Update label="2026-05-02" description="Weekly release" tags={["Features", "Updates"]}>

## New features

- **Risk Management Bank views.** Switch between a tree view and a grid view on the Risk Management Bank page to browse and edit risks the way that suits you. See [Risk Management Bank](/risk-bank-page).
- **Excursion risk grid view.** The Risk Management section on an excursion now offers a grid view alongside the tree view, with editable cells for faster updates. See [Risk management tab](/risk-management-tab).
- **Auto-detach on edit.** Editing certain columns in the excursion risk grid automatically detaches the inherited risk so your changes apply to that excursion only.

## Updates

- **Unified likelihood and severity selector.** Hazard and excursion hazard forms now use a single risk scale selector with descriptions, making it clearer which level you're choosing.
- **Likelihood and severity badges.** The risk bank tree now shows likelihood and severity as colored badges for at-a-glance scanning.
- **Refreshed risk icon colors.** Likelihood and severity icons use updated colors so risk levels are easier to tell apart.
- **Risk ratings in data grids.** Risk ratings now render directly in data grid cells across the risk bank and excursion risk views.
- **Responsive grid heights.** Data grids adapt their height to your viewport for a better fit on smaller screens.

</Update>

<Update label="2026-04-29" description="Weekly release" tags={["Features", "Updates", "Fixes"]}>

## New features

- **Excursion statuses and types.** Define your own excursion statuses with custom names, icons, and hex colors, and manage reusable excursion types from your workspace settings. See [Excursions](/excursions).
- **Excursion visual identity.** Personalise each excursion with an icon and color so it's easier to recognise across lists and pages.
- **Approval flows timeline.** Review approvals with a step-by-step timeline that shows detailed descriptions for each stage of the process.
- **Public excursion website.** Configure a public-facing website for an excursion using a new two-column layout for settings, with redaction controls for what is visible.
- **Forms linked to excursions.** Create and link forms directly from an excursion, with support for special excursion checkbox fields (such as student and staff selection) in the form builder. See [Forms](/forms).
- **Form submissions list.** Browse and review form submissions in a dedicated list and grid view with column metadata, search, and sorting.
- **Parent permission emails.** Send permission requests to parents by email with tracked send attempts and a parent-facing access flow.
- **Post-excursion surveys.** Collect feedback from students and staff after an excursion with a built-in survey workflow.
- **PDF exports.** Generate PDFs for risk management plans and itineraries directly from an excursion.
- **Excursion participant status tracking.** Track each participant's status on an excursion individually.
- **Task risk summary.** View a risk summary on excursion task controls so you can see which risks each task addresses.
- **Workspace excursion settings.** Configure workspace-wide defaults that flow through to excursion planning and the weather modal.
- **Workspace excursion statuses.** Manage status options across the workspace with backfill support for existing data.
- **Staff compliance.** Track staff compliance information with default values and review it from staff records. See [Staff](/staff).
- **Student swimming ability.** Capture and validate students' swimming ability on their record. See [Students](/students).
- **Workspace member invite reminders.** Automatically remind invited members who haven't yet joined the workspace.
- **Sign-in security.** Turnstile CAPTCHA is now part of the auth flows to better protect your workspace.

## Updates

- **Forms tab on excursions.** The "Resources" tab on excursions has been renamed to **Forms** to better match how you use it.
- **Excursion staff list.** The staff members section on an excursion now supports search, filter, and sort.
- **Excursion details loading.** Loading states for excursion detail pages are smoother and clearer.
- **Form builder.** The builder now includes save functionality, an updated settings modal, and form type selection.
- **Excursion roles.** Excursion roles can now have a description to clarify responsibilities.
- **Approval flows.** Each step in the approval flow timeline now includes more detailed descriptions.
- **Data grids.** Rows now use dynamic heights, and cells support empty-state tooltips and improved display options.

## Fixes

- Fixed sign-out form submission handling.
- Fixed excursion status handling for several edge cases.

</Update>
